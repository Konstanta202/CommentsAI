# VKCollector

Упрощённый сборщик данных из пабликов VK: посты и комментарии сохраняются в JSONL-файлы.
Без Kafka и баз данных — для быстрой выгрузки и изучения данных. Основа для дальнейшего развития в `VKParser`.

## Запуск

```bash
cp .env.example .env        # и вписать VK_TOKEN
mvn -q package
java -jar target/vk-collector.jar --groups <паблик1>,<паблик2> --since 2026-07-01
```

| Параметр | Описание |
|---|---|
| `--groups` | паблики через запятую: короткое имя, ссылка, `club123` или id |
| `--since`, `--until` | период публикации постов, `yyyy-MM-dd` |
| `--max-posts` | максимум постов на паблик |
| `--no-comments` | только посты |
| `--out-dir` | папка для результата (по умолчанию `data/`) |
| `--rps` | запросов к VK API в секунду (по умолчанию 3) |

## Результат

`data/run_<дата_время>/`:

- `groups.jsonl` — паблики: название, число подписчиков, город (`groups.getById`);
- `<паблик>_posts.jsonl` — посты: текст, дата, лайки, репосты, просмотры, число комментариев (`wall.get`);
- `<паблик>_comments.jsonl` — комментарии с лайками, ответы лежат в поле `thread.items` (`wall.getComments`).
